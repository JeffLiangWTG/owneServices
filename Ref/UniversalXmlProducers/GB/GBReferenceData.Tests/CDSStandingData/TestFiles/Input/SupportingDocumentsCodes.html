Guidance

Documents and other reference codes for data elements 2/3 of CDS

Use appendix 5 to find codes for data element 2/3 of the Customs Declaration Service (CDS) when importing into the UK.

Published 1 August 2018
From:
HM Revenue & Customs

Contents

  1. Appendix 5: General notes
  2. Appendix 5A: Documents and other reference codes (Union)
  3. Appendix 5A: Documents and other reference codes (National)
  4. Appendix 5B: Document status codes
  5. Appendix 5C: Document and other reference codes: Licence types

This appendix provides details of the relevant document codes, document status codes and details to be declared (for example, licences and certificates).

The appendix is in 4 parts.

Appendix 5: General notes

The UK Trade Tariff will identify any specific measures and document codes that may be required by the specific commodity code declared in DE 6/14 – 6/17.

This appendix contains details of all document and other reference codes, a description of their usage and provides guidance on the details to be declared against each code.

Use appendix 5A to identify any specific completion requirements for document codes which may be required by the commodity code.

The Procedure Code and Additional Procedure Code completion notes in Appendix 1: DE 1/10: Requested and Previous Procedure Codes and Appendix 2: DE 1/11: Additional Procedure Codes provide guidance on the document codes expected to be used in specific circumstances for the procedure concerned. They are not a definitive guide however and should be read along with the full list provided in appendix 5A.

Where a single goods item comprises of both Union and National codes declared in DE 2/3, any Union Codes (beginning with a letter) must be declared first.

The Union document codes and details to be declared are specified in Table 1 of appendix 5A.

The National document codes and details to be declared are specified in Table 2 of appendix 5A.

Notes

For the A series (of status codes)

Where permitted ‘attached’ can relate to a faxed copy of the original document, certificate, authorisation or licence.

In most cases a reference must be entered. This should either be as quoted on the document, certificate, authorisation or licence as contained in this appendix. For example:

  • DE2/3 for licences and customs authorisations
  • separate instructions such as Simplified Declaration Procedures (SD)
  • a trader’s own reference

For the X series of status codes and its relationship with the reference

When document codes are used for declaring licences the document reference is used to identify the licence type. For example, when XB is used the reference will be in the form of a country code and licence type (such as GBCAP). There is further information in other parts of appendix 5.
