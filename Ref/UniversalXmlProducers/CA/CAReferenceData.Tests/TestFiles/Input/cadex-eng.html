Customs Tariff - 2021
CADEX-formatted

More information

For more information about CADEX, visit the Electronic Data Interchange / Portal Clients section.

The CADEX files are intended for CADEX participants only.

CADEX is a proprietary message-formatting standard. It allows importers and customs brokers to file an electronic Form B3-3, Canada Customs Coding Form. CADEX participants can file directly to us, or through a third-party service provider.

Note: These CADEX-formatted Customs Tariff files have been compressed using WinZip®. To open these files it is recommended that you use PKUNZIP® or WinZip®.
