# Customs Data Provider C# Incremental Code Generator


This source code generator is used for generating Data Provider based on generated MessageBuilder and MessageBuilderMetadata class. Code generated uses the code generated 
by other code generators called `Customs.DataProviderAbstractClasses.CSharp.CodeGenerator` and `Customs.MessageBuilder.CSharp.CodeGenerator`.

Refer to the [documentation page](https://devops.wisetechglobal.com/wtg/CargoWise/_wiki/wikis/CargoWise.wiki/15537/Data-Provider-Generation) for more details and change logs.
