Tools required:
	- VS2017
	- SSAS(Microsoft Analysis Services Projects): From VS2017 Gallery
	- SSRS(Microsoft Reporting Services Projects):	From VS2017 Gallery
	- BISM Normalizer: From VS2017 Gallery

How to run a BI project:
	- Open .sln solution
	- Select "Integrated workspace" for Analysis Services instance.
	- Follow the following tutorial for add/update data: https://docs.microsoft.com/en-us/sql/analysis-services/tabular-modeling-adventure-works-tutorial
	- How to connect to remote server: https://docs.microsoft.com/en-us/sql/analysis-services/lesson-2-add-data
