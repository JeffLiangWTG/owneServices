How to generate C# from the XSDs.

1. Install .net 1.1:  http://www.microsoft.com/downloads/en/details.aspx?FamilyID=262D25E3-F589-4842-8157-034D1E7CF3A3
2. Install XSDObjectGenerator:  http://www.microsoft.com/downloads/en/details.aspx?familyid=89e6b1e5-f66c-4a4d-933b-46222bb01eb0&displaylang=en
3. Copy and paste the current XSD file into a new one, with a higher version number. Edit the new file to have your changes.
4.  Run XSDObjectGen over the new file, like this command line:
	XSDObjectGen.exe SCHEMAFILE.xsd /p /n:FQNAMESPACE /f:OUTPUTFILE.cs
	e.g. 
	C:\Dev\Enterprise\Product\Operations\Customs\GB\Core\CNS\Documentation\ICD> "c:\Program Files (x86)\XSDObjectGenerator\XSDObjectGen.exe" CNSICD_v2.xsd /p /n:Enterprise.Customs.GB.CNS /f:..\..\ServiceTasks\StatusUpdateICD\CNScargoStatus_AutoGenerated.cs
	or
	c:\Program Files (x86)\XSDObjectGenerator> XSDObjectGen.exe C:\Dev\Enterprise\Product\Operations\Customs\GB\Core\CNS\Documentation\ICD\CNSICD_v2.xsd /p /n:Enterprise.Customs.GB.CNS /f:C:\Dev\Enterprise\Product\Operations\Customs\GB\Core\CNS\ServiceTasks\StatusUpdateICD\CNScargoStatus_AutoGenerated.cs
