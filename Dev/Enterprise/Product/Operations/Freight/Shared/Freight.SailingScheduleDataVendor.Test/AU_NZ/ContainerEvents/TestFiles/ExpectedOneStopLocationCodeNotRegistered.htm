Unregistered 1-Stop Location Notification ((*OneStopLocationCode*))

A (*ContainerEventType*) container notification was received from 1-Stop for container
GATU0859042 (possibly others), originating from location 1-Stop Location for Testing with
1-Stop code '12345', but no organization is registered for this code.

Register the new 1-Stop code by following these steps:

  • Open the 1-Stop Location for Testing organization.
  • Enter the 1-Stop registration code. Go to the 'Config' tab, and enter a new record
    into the 'Registration Numbers / Codes' grid with the following details:
    • Country of Issue - 'AU'
    • Type - '1ST'
    • Registration Number / Code - '(*OneStopLocationCode*)'
  • You must register the organization as a 'Container Terminal' or a 'Container Yard' so that the system knows whether a Wharf Gate In/Out or a Container Pickup/Returned event has occurred. On the 'Details' tab of the organization make sure 'Services' is ticked.
  • Go to the the 'Services' tab of the organization. Make sure either 'Sea CTO'
    or 'Container Yard' is ticked.
  • Save your changes to the organization.
