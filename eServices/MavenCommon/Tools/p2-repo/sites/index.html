Welcome to the eServices P2 Repo - Eclipse plugins update site.

This web page provides automatic distribution and updates for the Eclipse plugins for eServices.

Plugin installation

To install the Eclipse plugins:

  1. In Eclipse, click on Help > Install New Software... > Add...
  2. In Add Repository, enter the following:
    • Name: eServices P2 Repo
    • Location: URL and click Add.
  3. All plugins from "eServices P2 Repo" should appear
  4. Choose Select All or use checkboxes to select plugins that you want to install
  5. Click Next to install selected plugins
  6. Finish
