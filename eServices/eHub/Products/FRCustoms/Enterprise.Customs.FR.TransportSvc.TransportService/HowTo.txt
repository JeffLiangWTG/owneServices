Packages: Edit paket.dependencies (in ehub directory) )paket.references (in projetcs) and BuildXML to add packages.
Then open command prompt, then cd eHub then paket.exe update. This will update paket.lock (keep only changes about current solution)
Set copy local true for all dlls so that they find their way in bin directory (deployment made easier)
New dlls should come from package directory (see Moq.dll properties in test project for instance))
