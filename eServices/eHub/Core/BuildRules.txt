To release a new version:
1. Change version number in AssemblyInfo.cs for all assemblies except  CargoWise.eHub.Core.Tests
2. Change post-build event for all projects to copy binary in Bin\<new_version_number> folder.
3. Change attributes in TFS to mark a folder with an old binaries as ReadOnly.

When adding a reference:
1. Use a file reference to the versioned bin folder
2. Set Copy Local = false
3. Set Specific Version = false
