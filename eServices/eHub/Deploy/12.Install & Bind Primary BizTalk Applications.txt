1. Copy "12a.CargoWise.eHub.Core.msi" and "12b.CargoWise.eHub.Gateway.msi" to BizTalk server machine.
2. Open BizTalk Administration, import "12a.CargoWise.eHub.Core.msi" first, a then "12b.CargoWise.eHub.Gateway.msi". Do not forget tick 
"Run Installation Application Wizard..." check box at then end of importing wizard. 
3. Make sure that Gateway app has a reference to Core app and all bindings (Send and Receive ports and locations) are in place.
