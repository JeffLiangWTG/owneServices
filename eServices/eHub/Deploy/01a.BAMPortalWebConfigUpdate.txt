1. Remove the registry lookup for the identity impersonation feature so that the callers identity is used instead.

Change this entry in C:\Program Files (x86)\Microsoft BizTalk Server 2013 R2\BAMPortal\web.config:
<identity impersonate="true" userName="registry key lookup..." password="registry key lookup..."/>

To this entry:
<identity impersonate="true" />



2. Allow Everyone access to the portal:

<allow roles="Everyone" />
