1. Copy 03a.ESB.Portal.zip to the server temp directory and unzip it as ESB.Portal
2. Locate the ESB.Portal\Install\Scripts\ESBFunctions.ps1 file, and open in notepad to replace all "v6.0A" with "v7.1", as we will install Windows 7 SDK 1.0 on the server. Also, replace all "BizTalk ESB Toolkit\2.0\" with "BizTalk ESB Toolkit\2.1\".
3. Copy ESB.Portal directory to inetpub\wwwroot
4. Install Windows 7 SDK 1.0 from \\Syd-sarc-1\softwarestore\Microsoft.com\Windows SDK 7.1\GRMSDKX_EN_DVD.iso
5. Open Powershell in admin mode, and type "Set-ExecutionPolicy unrestricted" and press enter. and then cd into the Install\Scripts directory of the portal.
6. Execute ESB.Portal\Install\Scripts\Management_Install.cmd, this will install ESB.Portal in the IIS default website.
7. Open the ESB.Portal's web.config file and change the connection strings to point to the correct database server, and change the Microsoft.ReportViewer.WebForms dlls from version 9 to version 8. (Actually, no need to change to 8, as 9 is now installed)
8. run C:\windows\Microsoft.Net\Framework\v3.0\Windows Communication Foundation\servicemodelreg.exe -i
9. Copy 03b.BizTalk ESB Exception Notification x64.zip to temp directory and unzip, and run setup.exe. 
10. Configure the connection string in c:\program files (x86)\Microsoft biztalk esb toolkit 2.0\Exception NOtification Service\BizTalk ESB Exception Notification.exe.config and restart the BizTalk ESB Exception Notification service.

NOTE, ensure the service and app pool users are in user groups and these groups have access to the ESB databases etc on sql server.

For guidance refer: http://dgoins.wordpress.com/2010/05/01/esb-toolkit-management-portal-installation-notes-from-the-field-2/
