For a 64-bit BizTalk process:
· Install 64-bit WCF LOB Adapter SDK. 
· Install 64-bit BizTalk Adapter Pack. 
· Install 64-bit LOB client and other required DLLs. 
· Install 32-bit BizTalk Adapter Pack. 
· Install 32-bit LOB client and other required DLLs.

Important: Make sure you choose custom install, and select all components of this adaptor to install.  
Note, if you are installing in a virtual environment, sometimes this install may stuck on working out the diskspace requirement. If this is the case, then you can open command prompt in elevated mode, and run 
msiexec.exe -package AdapterFramework.msi -qr 
which will install without the GUI prompts, and get around this problem.
